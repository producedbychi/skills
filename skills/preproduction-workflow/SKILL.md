# Preproduction workflow

This is one installable skill with three modes. Read only the reference for the work the user needs. The modes share project facts, but none requires a separate skill installation.

## Modes

| Mode | Use when | Read |
| --- | --- | --- |
| `treatment` | The concept or creative direction needs to be chosen or clarified. | [treatment](references/treatment.md) |
| `breakdown` | The user needs shots, assets, dependencies, or a crew or editor handoff. | [breakdown](references/breakdown.md) |
| `paperwork` | The user needs an estimate, scope, agreement draft, rights schedule, release checklist, change order, or invoice. | [paperwork](references/paperwork.md) |
| `full` | The user wants a preproduction package for the project. | Read the references as each stage becomes relevant. |

An explicit mode wins. Otherwise choose the smallest mode that answers the request. If the user invokes the skill without a project or clear task, offer these modes in plain language and ask which they want. Do not generate a full package merely because the skill was named.

## Shared project facts

Inspect the brief, project folder, brand material, supplied references, and existing approvals before asking questions. Carry one compact set of facts between modes: client and project name, objective, audience, deliverables and channels, constraints, dates, budget information, supplied assets, decision-makers, and approved or unresolved terms. Mark material facts as confirmed, proposed, or unknown. Do not turn an assumption in a treatment into a contractual fact.

For `full`, work in this order:

1. Develop the treatment and seek a decision on the direction when that decision changes the plan.
2. Break the chosen direction into an executable plan. If the direction is not approved, label the breakdown provisional.
3. Prepare only the paperwork the project calls for. Check its scope, deliverables, dates, fees, and rights against the plan. Draft terms are not signed terms. An invoice may be needed later, not during initial planning.

Finish with the outputs, decisions still needed, and any missing assets, permissions, or approvals.

Source-media selects and final-cut review belong to later stages. Do not present them as completed preproduction work. If the plan calls for AI video, hand the approved shot information to a suitable video-generation tool or skill when that work is requested; do not generate shots by default.
